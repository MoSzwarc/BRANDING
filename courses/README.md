# Course emblems

Notebook-system icon + cover for each Fit4Global course.
Palette: cream #F8F6F1 · charcoal #2C2C2C · gold #C4A35A · navy #0A1628.
Mark: the Fit4Global rising-figure logo, identical on every course.
Each course carries one hand-sketched object on its cover.

- `icons/f4g_<slug>_icon.png` — 1024×1024, for Notion page icons / TheMembers.
- `covers/f4g_<slug>_cover.png` — 2100×840 (1500×600 ratio), for Notion page covers.

Regenerate: `_source/render.html` + `_source/engine.js`, rendered headless (Playwright, toDataURL).
